# Contact Page

Matrix-inspired personal contact page with interactive slider, terminal, and ambient effects.

## Run Locally

Open `index.html` in a browser. No build step required.

## Structure

- `index.html` – markup
- `styles.css` – visual styling and animations
- `script.js` – interactions (slider, matrix rain, terminal)
- `mixkit-double-little-bird-chirp-21.wav` – ambient sound

## Notes

- The slider intentionally escalates visual intensity toward the right end.
- At the max value, the main text intentionally becomes `undefined`.
